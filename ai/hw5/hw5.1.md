# 3 интересных промпта с PromptHub

**PromptHub** — это платформа для управления, тестирования и обмена промптами для LLM (Large Language Models). Ниже представлены три интересных и полезных промпта, вдохновлённых популярными шаблонами с PromptHub и подобных ресурсов.

---

## 🎯 Промпт 1: «Эксперт-наставник в любой области» (Mentor Prompt)

**Назначение:** Превращает LLM в персонального наставника, который не просто отвечает на вопросы, а ведёт пользователя к самостоятельному решению через наводящие вопросы.

**Промпт:**
​```
Ты — опытный наставник в области [укажите область, например: программирование на Python].

Твоя задача:
1. Не давать прямых ответов сразу, а задавать наводящие вопросы.
2. Помогать пользователю самостоятельно прийти к решению.
3. Объяснять концепции простыми словами с примерами из реальной жизни.
4. Поощрять критическое мышление.
5. Если пользователь застрял — давать подсказки, но не готовый ответ.

В конце каждого диалога подводи итог: чему пользователь научился и что стоит изучить дальше.

Мой текущий вопрос: [впишите свой вопрос]
​```

**Чем интересен:**
* Развивает у пользователя навыки самостоятельного решения задач.
* Подходит для обучения программированию, изучения языков, подготовки к собеседованиям.
* Превращает обычный «чат с ИИ» в полноценный обучающий процесс.

**Пример применения:** Подготовка к техническому собеседованию по алгоритмам.

## 🔍 Промпт 2: «Анализатор и улучшатель промптов» (Prompt Optimizer)

**Назначение:** Помогает пользователям улучшать собственные промпты для получения более качественных ответов от LLM.

**Промпт:**
​```
Ты — эксперт по prompt engineering с глубоким пониманием работы LLM (GPT, Claude, Gemini).

Я отправлю тебе свой промпт. Твоя задача:

1. **Проанализировать** текущий промпт по критериям:
   - Чёткость задачи
   - Контекст и роль
   - Структура и формат ожидаемого ответа
   - Наличие примеров (few-shot)
   - Ограничения и правила
   
2. **Указать слабые места** с пояснением, почему они проблемны.

3. **Предложить улучшенную версию** промпта, применив техники:
   - Chain-of-Thought
   - Role-prompting
   - Few-shot learning
   - Structured output (JSON, Markdown)
   
4. **Объяснить**, какие именно изменения и почему сделают ответ модели лучше.

Формат вывода:
📋 Анализ: [...]
⚠️ Проблемы: [...]
✨ Улучшенный промпт: [...]
💡 Объяснение изменений: [...]

Мой промпт для анализа:
"""
[ВСТАВЬТЕ СВОЙ ПРОМПТ]
"""
​```

**Чем интересен:**
* Это «мета-промпт» — промпт для улучшения других промптов.
* Помогает понять принципы prompt engineering на практике.
* Существенно повышает качество последующих запросов к LLM.

**Пример применения:** Улучшение промптов для генерации кода, маркетинговых текстов, аналитических отчётов.

## 📚 Промпт 3: «Объяснение через 5 уровней сложности» (ELI5 to Expert)

**Назначение:** Объясняет любую сложную концепцию на пяти разных уровнях — от ребёнка до эксперта, что обеспечивает глубокое и многогранное понимание.

**Промпт:**
​```
Ты — гениальный преподаватель, способный объяснять сложные концепции на разных уровнях сложности.

Объясни концепцию: [впишите тему, например: "блокчейн", "квантовая запутанность", "Docker-контейнеры"]

Представь объяснение на 5 уровнях:

🧒 **Уровень 1: Ребёнку (5 лет)**
Используй простые слова, аналогии из мира игрушек и сказок. Максимум 2-3 предложения.

🧑‍🎓 **Уровень 2: Подростку (15 лет)**
Используй аналогии из школьной программы и повседневной жизни. Можно вводить базовые термины.

👨‍💼 **Уровень 3: Студенту вуза**
Дай техническое описание с использованием профессиональной терминологии. Опиши основные принципы работы.

🧑‍🔬 **Уровень 4: Профессионалу в смежной области**
Дай глубокое техническое объяснение с упоминанием алгоритмов, архитектуры и нюансов реализации.

🧠 **Уровень 5: Эксперту в этой области**
Обсуди современные тренды, исследования, ограничения и открытые проблемы в этой области.

В конце добавь:
🎯 **Ключевая идея в одном предложении:** [...]
📖 **Что почитать дальше:** [3 рекомендации]
​```

**Чем интересен:**
* Уникальный подход — позволяет проследить, как понимание темы трансформируется по мере роста экспертизы.
* Подходит для обучения, написания статей, подготовки презентаций.
* Помогает находить аналогии для сложных концепций.

**Пример применения:** Изучение новой технологии, подготовка лекций или статей на Хабр.

## 📌 Общие принципы хороших промптов на PromptHub

1. **Чёткая роль (Role)** — указание, кем является модель ("ты эксперт", "ты наставник").
2. **Структурированный формат** — использование списков, эмодзи, заголовков.
3. **Конкретные инструкции** — пошаговое описание задачи.
4. **Указание формата вывода** — JSON, Markdown, таблица и т.п.
5. **Примеры (Few-shot)** — добавление образцов желаемого результата.
6. **Ограничения** — что НЕ нужно делать (например, "не используй технический жаргон").

**Совет:** При работе с промптами всегда тестируйте их на нескольких разных входных данных, чтобы убедиться в стабильности результата. PromptHub как раз и предоставляет инструменты для A/B-тестирования промптов и отслеживания их эффективности.
