# Идеи мультимодальных AI-приложений

## Что такое мультимодальность

Мультимодальный AI — это модель, которая одновременно работает с несколькими типами данных: текстом, изображениями, аудио, видео, структурированными данными. Комбинируя модальности, можно решать задачи, недоступные однотипным моделям.

---

## 🏗️ 1. Django Error Inspector

**Модальности: скриншот + текст трейсбека → текстовый отчёт**

Разработчик делает скриншот экрана (Swagger UI с 500-ошибкой или PyCharm с красной подсветкой) и отправляет его агенту вместе с текстом трейсбека. Модель видит визуальный контекст (какой именно эндпоинт, как выглядит запрос) **и** текст ошибки одновременно — и возвращает точную правку с номером строки.

Обычный чат-бот требует вставить код вручную; здесь достаточно скриншота.

**Стек:** GPT-4o Vision + LangChain Tool + Django AST-анализатор

**Пример взаимодействия:**
```
Вход: [скриншот PyCharm с красной строкой] + трейсбек
Выход:
🔴 ImportError в bookings.py, строка 6
Причина: circular import с properties.py
Правка: перенести импорт внутрь метода to_representation()
```

## 🏠 2. StayNest Property Validator

**Модальности: фото объявления + текст описания → скоринг качества**

Арендодатель загружает фото квартиры и текст объявления. Агент проверяет:

- Совпадает ли описание с фото (заявлен балкон — есть ли он на снимке?)
- Насколько профессиональны фотографии (освещение, ракурс, чистота)
- Соответствует ли цена рынку Германии для данного типа жилья

Результат — автоматический скоринг объявления перед публикацией.

**Стек:** Vision LLM + Embedding-поиск по базе объявлений (FAISS) + DRF endpoint

**Пример вывода:**
```json
{
  "score": 74,
  "issues": [
    "Описание упоминает 'панорамный вид', на фото — стена соседнего здания",
    "Цена 1850€ выше медианы для 2-комнатных в Nauen на 18%"
  ],
  "suggestions": ["Переснять кухню при дневном освещении"]
}
```

## 🎧 3. Code Review по голосу

**Модальности: аудио + файл кода → аннотированный код + аудиоответ**

Разработчик наговаривает голосовой комментарий к pull request: *«здесь мне кажется неправильная логика валидации дат бронирования»* — и прикрепляет файл. Агент:

1. Транскрибирует речь (Whisper)
2. Находит упомянутый участок кода по ключевым словам
3. Анализирует логику
4. Возвращает аудиообъяснение + исправленный фрагмент

Удобно для code review в дороге, без клавиатуры.

**Стек:** Whisper (speech-to-text) + GPT-4o + TTS (text-to-speech) + LangChain

## 🗺️ 4. Визуальный планировщик путешествий

**Модальности: фото локации + текстовые предпочтения → маршрут на карте**

Пользователь фотографирует вид из окна отеля или случайную уличную сцену, добавляет текстом: *«хочу что-то тихое, с едой и историей»*. Агент:

- Распознаёт геолокацию по визуальным признакам (архитектура, вывески, ландшафт)
- Накладывает текстовые предпочтения
- Генерирует маршрут с описанием каждой точки

Актуально для спонтанных путешествий — не нужно знать название района.

**Стек:** Vision LLM (геолокация по фото) + текстовые embeddings + Google Maps API

## 🎓 5. Ментор по написанию кода для начинающих

**Модальности: видеозапись экрана + код → персонализированный разбор**

Студент записывает короткое видео своей работы в IDE — агент видит, где он тормозит, куда водит мышкой, где возникает ошибка. Комбинируя видео (что делает студент) и код (что написано), модель понимает **процесс**, а не только результат.

Вместо «здесь ошибка» — «ты запустил сервер до `migrate`, вот пошаговый порядок действий».

**Стек:** Video Understanding (Gemini 1.5 Pro) + AST-анализатор + адаптивный промпт по уровню ошибок

## С чего начать

Самая реалистичная для быстрой реализации — **Django Error Inspector**: GPT-4o уже принимает скриншоты через `base64` или URL, нужно лишь обернуть это в LangChain-инструмент.

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
import base64

def analyze_screenshot(image_path: str, traceback_text: str) -> str:
    with open(image_path, "rb") as f:
        image_data = base64.b64encode(f.read()).decode("utf-8")

    llm = ChatOpenAI(model="gpt-4o", temperature=0)
    message = HumanMessage(content=[
        {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{image_data}"}},
        {"type": "text", "text": f"Traceback:\n{traceback_text}\n\nНайди ошибку и дай точную правку."}
    ])
    return llm.invoke([message]).content
```
